# Security Policy

## Supported versions

Security fixes are currently provided for the latest version on the default
branch. No older release series are guaranteed to receive security updates.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Use GitHub's **Report a vulnerability** option on the repository's Security
tab to send a private report. Include the affected version or commit, impact,
reproduction details and any suggested mitigation. Redact credentials,
personal data and other secrets from the report.

If private vulnerability reporting is unavailable, contact a repository owner
directly through GitHub and ask for a private channel. Do not publish details
until the maintainers have had a reasonable opportunity to investigate and
coordinate a fix.

The maintainers will acknowledge reports as soon as practical, assess the
impact and coordinate disclosure with the reporter. There is no guaranteed
response or remediation timeframe.
